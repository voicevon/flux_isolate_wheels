# flux_loader

`flux_loader` 是一个基于 ESP32 的步进电机控制与物料传输系统。该系统通过精确控制 8 个步进电机，驱动 8 个一体化托架转轮，实现物料（芦笋/Asparagus）的节拍式顺序传输与分发。

---

## 1. 硬件架构与控制

- **核心控制器**：ESP32
- **执行机构**：8 个步进电机（分别控制 8 个托架转轮）
- **机械结构**：
  - 系统包含 8 个托架转轮（托架与转轮一体化设计）。
  - **托架转轮编号**：从左向右依次为 **1号托架转轮** 至 **8号托架转轮**（1号在最左端入料，8号在最右端出料）。
  - **传输方向**：物料（芦笋）由左向右依次传输，即：
    $$\text{1号托架转轮} \rightarrow \text{2号} \rightarrow \text{3号} \rightarrow \text{4号} \rightarrow \text{5号} \rightarrow \text{6号} \rightarrow \text{7号} \rightarrow \text{8号} \rightarrow \text{出料口}$$

---

## 2. 物料状态定义

对于任意托架转轮上的芦笋数量，系统主要关心以下三种状态：
1. **0 个芦笋**：表示托架为空。
2. **1 个芦笋**：表示托架上仅有单个芦笋。
3. **2 个及以上芦笋（2+）**：多物料状态（2 个与 2 个以上在业务处理逻辑中视为相同状态）。

---

## 3. 业务控制逻辑（托架状态机）

系统按**节拍**运行：每个 `load` 命令携带 8 个托架的芦笋数量，设备按**成对配对状态机**判定规划动作（详细见 **[doc/节拍状态图.md](doc/节拍状态图.md)** 与 **[doc/节拍逻辑.md](doc/节拍逻辑.md)**）：

1. **成对动作产生**：动作以**供方（左）→ 接收方（右，编号加一）**成对产生，要么成对、要么整对不产生。
2. **成对条件**：接收方处于**锁定**、接收方为空（count=0）、接收方的右侧无料（可解锁）。
3. **配对分支**：
   - 锁定 + count=1 → **美妙 + 接美妙**（供方 60°/0°/30°，接收方 30°/60°/0°）；
   - 锁定 + count≥2 → **超载 + 接超载**（供方 28°/0°/0° → 转世，接收方 0°/90°/0° → 锁定）；
   - 转世（上一拍超载分解） → **新生 + 接新生**（供方 32°/0°/30° → 锁定，接收方 30°/60°/0° → 锁定）。
4. **出料口**：8 号轮右侧为出料口（虚拟接收位，永远为空、可解锁），8 号轮自身有料时永远可以配对出料。
5. **执行模型**：一次 load 规划 3 个节拍，每拍内 8 路电机各走各的步数，全部到位后进入下一拍，三拍完成后发 `done`。

---

## 4. 多电机执行策略

8 个步进电机各接**独立 STEP 引脚**，由 FastAccelStepper 独立控制加减速，同一节拍内**同时启动、各走各的目标步数**（减速比 54:18 = 3:1，1/16 细分下 90° = 2400 步、60° = 1600 步、30° = 800 步，均为电机轴步数）。方向信号经 74HC595 串行输出；驱动器使能脚 (EN) 直接接地常使能，无软件使能概念。各电机的逻辑方向与物理方向映射由 `DIR_INVERT_MASK`（config.h）逐机配置，安装反向的电机自动求反。

> **细分设置**：所有驱动器共用同一组细分控制引脚（MS1 / MS2 / MS3），统一配置为 1/16 细分。

---

## 5. 接口与引脚定义 (GPIO)

| 功能 | GPIO | 说明 |
| :--- | :--- | :--- |
| STEP0 ~ STEP7 | 32, 33, 25, 26, 27, 14, 12, 13 | 8 路电机独立步进脉冲（对应 1~8 号轮） |
| MS1 / MS2 / MS3 | 4 / 16 / 17 | 细分选择（全核共用） |
| 74HC595 数据 (DS) | 21 | DIR 串行输出 |
| 74HC165 数据 (Q7) | 34 | HOME 串行输入 |
| 移位时钟 (SHCP/CP) | 19 | 595 与 165 共享 |
| 锁存 (STCP/PL) | 18 | 595 与 165 共享 |
| 入口光电传感器 | 39 | 检测物料落入入口 |
| 板载 LED | 2 | 心跳/诊断指示 |
| 驱动器 EN | — | 接地常使能，未接 GPIO |
