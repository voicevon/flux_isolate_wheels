# flux_loader

`flux_loader` 是一个基于 ESP32 的步进电机控制与物料传输系统。该系统通过精确控制 8 个步进电机，驱动 8 个一体化托架转轮，实现物料（芦笋/Asparagus）的节拍式顺序传输与分发。

---

## 1. 硬件架构与控制

- **核心控制器**：ESP32
- **执行机构**：8 个步进电机（分别控制 8 个托架转轮）
- **机械结构**：
  - 系统包含 8 个托架转轮（托架与转轮一体化设计）。
  - **托架转轮编号**：从右向左依次为 **1号托架转轮** 至 **8号托架转轮**。
  - **传输方向**：物料（芦笋）由左向右依次传输，即：
    $$\text{8号托架转轮} \rightarrow \text{7号} \rightarrow \text{6号} \rightarrow \text{5号} \rightarrow \text{4号} \rightarrow \text{3号} \rightarrow \text{2号} \rightarrow \text{1号}$$

---

## 2. 物料状态定义

对于任意托架转轮上的芦笋数量，系统主要关心以下三种状态：
1. **0 个芦笋**：表示托架为空。
2. **1 个芦笋**：表示托架上仅有单个芦笋。
3. **2 个及以上芦笋（2+）**：多物料状态（2 个与 2 个以上在业务处理逻辑中视为相同状态）。

---

## 3. 业务控制逻辑（节拍式运行）

系统按**节拍（周期）**运行。在每一个工作周期开始时，各个托架转轮的动作由其自身及相邻右侧托架转轮的物料状态决定。

### 核心规则

1. **1号托架转轮（最右侧出口）**：
   - 处于固定工作状态，每个节拍**固定旋转 90°**。

2. **2号至8号托架转轮（$N$ 号托架转轮，其中 $N \ge 2$）**：
   - 是否转动及转动角度，取决于其**右侧相邻托架转轮（$N-1$ 号托架转轮）**的物料状态，以及**自身**的物料状态。

| 右侧 $N-1$ 号托架转轮状态 | 自身 $N$ 号托架转轮状态 | $N$ 号托架转轮动作 | 说明 |
| :--- | :--- | :--- | :--- |
| **有芦笋** ($\ge 1$) | 任意 | **停止** (旋转 0°) | 避免向已有芦笋的右侧托架转轮继续输送物料，防止堆积或干涉 |
| **无芦笋** ($== 0$) | **无芦笋** ($== 0$) | **旋转 90°** | 右侧为空且自身为空时，正常旋转以接收左侧（上游）传来的物料 |
| **无芦笋** ($== 0$) | **有 1 个芦笋** | **旋转 90°** | 将单物料向前输送 |
| **无芦笋** ($== 0$) | **有多个芦笋** ($\ge 2$) | **旋转 22.5°** | 多物料状态下，通过减小旋转角度降低传输速度，将多根芦笋逐步分解为单根后再向右侧输送 |

> 节拍完整生命周期、执行模型、参数速查与示例推演见 **[doc/节拍逻辑.md](doc/节拍逻辑.md)**。

## 4. 多电机执行策略

8 个步进电机各接**独立 STEP 引脚**，由 FastAccelStepper 独立控制加减速，同一节拍内**同时启动、各走各的目标步数**（减速比 54:18 = 3:1，1/16 细分下 90° = 2400 步、22.5° = 600 步，均为电机轴步数）。方向信号经 74HC595 串行输出；驱动器使能脚 (EN) 直接接地常使能，无软件使能概念。各电机的逻辑方向与物理方向映射由 `DIR_INVERT_MASK`（config.h）逐机配置，安装反向的电机自动求反。

> **细分设置**：所有驱动器共用同一组细分控制引脚（MS1 / MS2 / MS3），统一配置为 1/16 细分。

## 5. 接口与引脚定义 (GPIO)

| 功能 | GPIO | 说明 |
| :--- | :--- | :--- |
| STEP0 ~ STEP7 | 13, 12, 14, 27, 26, 25, 33, 32 | 8 路电机独立步进脉冲 |
| MS1 / MS2 / MS3 | 4 / 16 / 17 | 细分选择（全核共用） |
| 74HC595 数据 (DS) | 21 | DIR 串行输出 |
| 74HC165 数据 (Q7) | 34 | HOME 串行输入 |
| 移位时钟 (SHCP/CP) | 19 | 595 与 165 共享 |
| 锁存 (STCP/PL) | 18 | 595 与 165 共享 |
| 入口光电传感器 | 39 | 检测物料落入入口 |
| 板载 LED | 2 | 心跳/诊断指示 |
| 驱动器 EN | — | 接地常使能，未接 GPIO |
